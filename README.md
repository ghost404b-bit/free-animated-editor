# Text-to-Video Studio

Une petite app web gratuite qui transforme un texte en vidéo animée dans le navigateur, sans abonnement ni API payante.

## Ce que fait l’application

- Saisis un texte ou une phrase
- Choisis un style visuel
- La vidéo se génère automatiquement en animation sur un canvas
- Tu peux exporter la séquence au format WebM

## Démarrer

1. Ouvre `index.html` dans ton navigateur.
2. Écris un texte dans le champ.
3. Clique sur `Générer la vidéo`.
4. Clique sur `Exporter WebM` pour télécharger la vidéo.

## Fichiers

- `index.html` : interface utilisateur
- `style.css` : design du studio
- `script.js` : génération des scènes et export vidéo

## Remarque

Cette version est une solution locale, simple et gratuite inspirée du concept “texte -> vidéo animée”. Elle ne repose pas sur une IA cloud ni sur des outils payants.

Si tu veux, je peux aussi te faire une version plus avancée avec :
- plusieurs scènes personnalisées
- texte en anglais/français
- musique
- génération de transitions
- export MP4
- style plus “AI cinematic”
